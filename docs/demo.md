# Una demo que cuenta una historia

## La idea para ganar

**La audiencia no rellena una encuesta: cambia lo que sucede en el escenario.** Convierte esa frase en una demostración observable. Invita a una persona real y deja que su aportación cambie el slide frente a los jueces.

## Guion de menos de tres minutos

| Tiempo | Acción | Qué decir |
| --- | --- | --- |
| 0:00–0:20 | Crear sala y compartir enlace con un teléfono | “El último slide todavía no existe. Hoy lo escriben ustedes.” |
| 0:20–0:50 | El invitado envía una sugerencia y el anfitrión la incorpora | “La audiencia puede mejorar una explicación sin interrumpirla.” |
| 0:50–1:15 | Crear una constelación y enviar una conclusión desde el móvil | “Cada idea deja una huella en la presentación.” |
| 1:15–1:40 | Pedir una investigación con fuente | “Firecrawl trae evidencia; OpenAI la convierte en un slide mientras hablamos.” |
| 1:40–2:00 | Consultar un correo preparado y convertirlo en slide | “Alguien que no está en la sala también puede aportar.” |
| 2:00–2:20 | Activar momentos, decir una frase graciosa; mostrar el meme | “El escenario escucha solo cuando yo lo permito.” |
| 2:20–2:50 | Elegir conclusiones y mostrar el cierre colectivo | “Esta presentación termina con lo que entendieron, no solo con lo que dije.” |

## Preparación

1. Usar la URL pública. Crear la sala en el navegador del presentador y conservar esa sesión.
2. Abrir el enlace compartido en otro dispositivo o perfil para la audiencia.
3. Activar el buzón antes de grabar. Enviar personalmente un correo breve de ejemplo y pulsar **Consultar correos**. El envío no es automático.
4. Probar el micrófono en el navegador/dispositivo de la demo. Si su servicio de reconocimiento no responde, el campo de comandos ejecuta las mismas acciones y debe presentarse como alternativa por texto.
5. Usar una fuente web legible y esperar a que la operación aparezca completada. Las llamadas de terceros no son instantáneas.
6. Elegir al menos una conclusión antes del cierre. Usar **Presentar** para mostrar solo el escenario.

## Más ideas para siguientes iteraciones

Estas son propuestas, no funciones ya implementadas:

- **Bifurcación democrática:** una votación abre el siguiente capítulo; el presentador confirma la ruta.
- **Abogado del diablo:** la audiencia pide una objeción; Firecrawl busca evidencia y OpenAI construye un contrapunto con fuentes.
- **Lo entendimos distinto:** comparar la intención del presentador con las conclusiones de la audiencia para revelar malentendidos.
- **Cápsula de la charla:** un resumen verificable con fuentes y conclusiones que el anfitrión revisa antes de enviar por AgentMail.
- **Un minuto para explicarlo:** al subir las preguntas, ofrecer al presentador una analogía y un visual para volver a explicar el tema.

Para esta entrega, mantener el foco en sugerencia → evidencia → cierre colectivo. Los memes son un momento de sorpresa; la colaboración es el motivo para volver a usar Slidex.
